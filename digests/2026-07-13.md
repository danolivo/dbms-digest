_Beta week: PostgreSQL 19 Beta 2 shipped Jul 16, and the price of late beta showed up two

## PostgreSQL

- **[PostgreSQL 19 Beta 2 released](https://www.postgresql.org/about/news/postgresql-19-beta-2-released-3350/)** — second beta, GA still targeted around September/October. *(PGDG · postgresql.org, Jul 16)*
    - fixes since Beta 1: `vacuumdb --analyze-in-stages` regression on partitioned tables, several `FOR PORTION OF` and SQL/PGQ property-graph fixes, `REPACK` worker not cleaned up on FATAL exit, a race in logical-decoding activation, autovacuum's multixact-age score going infinite, `postgres_fdw` imported-statistics handling
    - reverted: non-text output formats for `pg_dumpall`
- **[GROUP BY ALL reverted from PG19](https://mail-archive.com/pgsql-committers@lists.postgresql.org/msg47406.html)** — post-commit review (reported by Chao Li) found the new syntax missed the special handling of entries that also appear in ORDER BY, returning wrong results when ORDER BY specifies non-default equality semantics; fixing it cleanly was judged too much churn for late beta, so the feature waits for v20. *(Daniel Gustafsson, Tom Lane · postgres git, Jul 17)* `[reverted]`
- **[Sequence-refresh concurrency guard reverted](https://mail-archive.com/pgsql-committers@lists.postgresql.org/msg47413.html)** — the fix that made `ALTER SUBSCRIPTION ... REFRESH SEQUENCES` error out while a sequencesync worker was running (closing the stale-value race found in review two weeks ago) caused intermittent buildfarm failures and was judged too inconvenient to keep; the underlying race gets a different fix in a follow-up. *(Amit Kapila · postgres git, Jul 17)* `[reverted]`
- **[GiST index-only scans could return misaligned column data](https://mail-archive.com/pgsql-committers@lists.postgresql.org/msg47398.html)** — fix for a column-alignment issue in GiST index-only scans, backpatched across the stable branches. *(Peter Geoghegan · postgres git)* `[committed]`
- **[Planner: edge case in remove_useless_result_rtes() with outer joins](https://mail-archive.com/pgsql-committers@lists.postgresql.org/msg47419.html)** — wrong-plan edge case when removing useless RTE_RESULT rels under outer joins, fixed and backpatched; same week the grammar [restored `|` and `->` as prefix operators](https://mail-archive.com/pgsql-committers@lists.postgresql.org/msg47417.html) after a regression from earlier parser work. *(Tom Lane · postgres git)* `[committed]`
- **Master grab-bag** — [pg_controldata now shows logical decoding status](https://mail-archive.com/pgsql-committers@lists.postgresql.org/msg47364.html) *(Masahiko Sawada)*; [REASSIGN OWNED fixed for subscriptions in other databases](https://mail-archive.com/pgsql-committers@lists.postgresql.org/msg47415.html) *(Jeff Davis)*; [uuidv7() rejects infinite/out-of-range interval shifts](https://mail-archive.com/pgsql-committers@lists.postgresql.org/msg47359.html) *(Masahiko Sawada)*; [case-insensitive LIKE prefix selectivity fixed](https://mail-archive.com/pgsql-committers@lists.postgresql.org/msg47303.html) *(Jeff Davis)*; the ancient SQL function [getpgusername() is gone](https://mail-archive.com/pgsql-committers@lists.postgresql.org/msg47368.html) *(Michael Paquier)*; platform floors raised to [Visual Studio 2022](https://mail-archive.com/pgsql-committers@lists.postgresql.org/msg47346.html) and [ICU 55](https://mail-archive.com/pgsql-committers@lists.postgresql.org/msg47347.html) *(Peter Eisentraut)* — the matching Tcl 8.6 bump was [reverted the same week](https://mail-archive.com/pgsql-committers@lists.postgresql.org/msg47349.html). `[committed]`

### Ecosystem releases

- **[Odyssey 1.5.1](https://www.postgresql.org/about/news/odyssey-151-released-3348/)** — Yandex's multi-threaded connection pooler; a large extended-protocol refactor headlines. *(Yandex · postgresql.org news, Jul 14)*
    - extended-protocol conformance fixes: correct `Close` handling, `DEALLOCATE ALL`, correct `COPY`; pipelining performance improved
    - new: simple shared pools, `pool_pin_on_listen` for transaction pooling, `cpu_affinity`, queue-time metrics (`avg_wait_time`/`total_wait_time`), NOTICE after configurable queue wait, `server_drop_on_cached_plan_error`
    - fixes: cancel-connection race, auth_query fixes, pool-size recheck after server creation
- **[plx: stored functions in PHP, JavaScript, Python, Ruby — even COBOL](https://github.com/commandprompt/plx)** — transpiles other languages to PL/pgSQL rather than embedding interpreters; a curious alternative to the PL zoo. *(Command Prompt · via Postgres Weekly #657)* `[publish date unverified]`
